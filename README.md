# Find Expression

Функция для поиска выражения, которое даёт заданное число.

Используются цифры от `9` до `0` в фиксированном порядке. Между ними можно поставить `+`, `-` или объединить соседние цифры.

Примеры:

`findExpression(100)` → `98-7-6+5+4+3+2+1+0`

`findExpression(200)` → `9-8+7-6-5-4-3+210`
